Published · Hugging Face

Accent-Based Regional Origin Identification

Pondicherry University

Developed a multiclass accent classification system by extracting and temporally aligning 7 speech features — MFCC, Mel-spectrogram, Spectral Contrast, Chroma, ZCR, RMS, and Tonnetz — from 1,164 audio samples. Created a robust dataset and designed an evaluation pipeline for comparing multiple model architectures.

Benchmarked 5 architectures (SVM, Logistic Regression, ANN, 1D-CNN, 2D-CNN) with regularisation, data augmentation, and class weighting. The optimised 4-block 2D-CNN achieved 97% test accuracy, outperforming traditional ML baselines by over 4 percentage points. Applied class balancing and regularisation to improve generalisation and reduce overfitting during deployment.

02 Jan 2026 – Apr 2026
Research · Geospatial AI

Mineral Region Segmentation via Multispectral Remote Sensing

Pondicherry University

Engineered an end-to-end semantic segmentation pipeline for mineralisation mapping over Salem District (9,561 km²) using Landsat-8 satellite imagery (7 spectral bands, 30 m resolution). Applied PCA reduction (97.68% variance retained, 3 components) and 15-channel multi-source geospatial feature fusion.

Resolved a severe 2,509:1 class imbalance via 10× mineral augmentation and a Weighted BCE + Dice loss combination. Independently designed and comparatively trained three encoder-decoder architectures (UNet, Attention UNet, ResUNet) using the AdamW optimiser. Identified ResUNet-15ch as the most operationally effective model, achieving the highest mineral recall (92.42%) critical for geological survey applications.
