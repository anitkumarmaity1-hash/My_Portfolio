Research · Geospatial AI

Mineral Region Segmentation via Multispectral Remote Sensing

Pondicherry University

Engineered an end-to-end semantic segmentation pipeline for mineralization mapping over Salem District (9,561 km²) using Landsat-8 satellite imagery (7 bands, 30m). Applied PCA reduction (97.68% variance, 3 components) and 15-channel multi-source geospatial feature fusion. Resolved 2,509:1 class imbalance via 10× mineral augmentation and Weighted BCE + Dice loss. Comparatively trained UNet, Attention UNet, and ResUNet architectures using AdamW.
